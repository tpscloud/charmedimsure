# Help dialog over a log pane

Write a full screen Bubble Tea v2 program that uses Lip Gloss v2
(`charm.land/lipgloss/v2`) to show a pane of thirty colored log lines. Pressing
`?` opens a centered, bordered help dialog on top of the pane; the lines behind
the dialog must keep their colors and alignment outside the dialog's rectangle.
Clicking outside the dialog or pressing `esc` closes it; clicking inside it does
nothing. Colors adapt to a light or dark terminal background. `q` quits.

Return the complete `main.go`.
