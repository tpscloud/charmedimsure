# charmedimsure

![charmed, I'm sure](https://raw.githubusercontent.com/tpscloud/charmedimsure/main/assets/banner-terminal.png)

Skills for AI coding agents that cover the <a href="https://charm.land/" target="_blank" rel="noopener noreferrer">Charm ecosystem</a>:

- <a href="https://github.com/charmbracelet/bubbletea" target="_blank" rel="noopener noreferrer">Bubble Tea</a>
- <a href="https://github.com/charmbracelet/bubbles" target="_blank" rel="noopener noreferrer">Bubbles</a>
- <a href="https://github.com/charmbracelet/lipgloss" target="_blank" rel="noopener noreferrer">Lip Gloss</a>
- <a href="https://github.com/charmbracelet/huh" target="_blank" rel="noopener noreferrer">Huh</a>
- <a href="https://github.com/charmbracelet/log" target="_blank" rel="noopener noreferrer">Log</a>
- <a href="https://github.com/charmbracelet/glamour" target="_blank" rel="noopener noreferrer">Glamour</a>
- <a href="https://github.com/charmbracelet/gum" target="_blank" rel="noopener noreferrer">gum</a> (CLI)
- <a href="https://github.com/charmbracelet/vhs" target="_blank" rel="noopener noreferrer">vhs</a> (CLI)

The Go libraries use their v2 `charm.land` import paths.

Every Go example in these skills lives under `examples/` and is built and
tested in CI against the pinned module versions, so the snippets do not drift.

## Install

Install with Vercel's <a href="https://skills.sh" target="_blank" rel="noopener noreferrer">skills CLI</a>:

```sh
npx skills add tpscloud/charmedimsure
```

> [!NOTE]
> This is the recommended route. One command installs into Claude Code, Codex,
> and dozens of other agents from one shared copy, either per project (committed
> with your code) or for your user. It needs no clone, and `npx skills update`
> pulls new versions later.

It asks which skills and agents to install. Add `--skill charmed-bubbletea`
(repeatable) to pick skills, `-a claude-code` or `-a codex` to pick an agent,
and `-g` to install for your user instead of the current project. `--list`
shows the skills without installing.

### From a checkout

The skills also load straight from a clone of this repository. Replace
`/path/to/charmedimsure` with its absolute path.

Claude Code, as a plugin for one session (skills are then named
`/charmedimsure:charmed-gum` and so on):

```sh
claude --plugin-dir /path/to/charmedimsure
```

Claude Code or Codex, as personal skills that stay installed:

```sh
# Claude Code
mkdir -p "$HOME/.claude/skills"
ln -s /path/to/charmedimsure/skills/charmed-* "$HOME/.claude/skills/"

# Codex
mkdir -p "$HOME/.agents/skills"
ln -s /path/to/charmedimsure/skills/charmed-* "$HOME/.agents/skills/"
```

Start a new session afterwards. Symlinked skills follow the checkout, so keep
it in place.

### Examples

The Go programs the skills cite live in `examples/` at the repository root,
with `examples/go.mod`. An installed skill links to them on GitHub. To run
one, clone the repository and run it from `examples/`, for example
`go run ./charmed-bubbletea/counter`.
