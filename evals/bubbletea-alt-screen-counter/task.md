# Counter TUI in Bubble Tea v2

Write `main.go` for a new Go module that uses Bubble Tea v2 (`charm.land/bubbletea/v2`).

The program shows a counter in the terminal's alternate screen. `+` increments it,
`-` decrements it, and `q` or `ctrl+c` quits. The window title shows the current
count, for example `count: 3`.

Return the complete `main.go`.
