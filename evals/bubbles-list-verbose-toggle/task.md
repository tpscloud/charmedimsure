# A list where v toggles details

Using Bubbles v2 (`charm.land/bubbles/v2/list`) inside a Bubble Tea v2 program,
build a list of five project tasks. Pressing `v` must toggle a "verbose" flag that
shows each task's description in the status line. Pressing `v` must never quit
the program. `ctrl+c` quits.

Return the complete `main.go`.
