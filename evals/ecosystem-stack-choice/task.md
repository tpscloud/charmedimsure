# Pick the Charm stack for a new tool

A new Go command-line tool needs: an interactive setup questionnaire, a
full-screen dashboard with a scrollable table, styled output, and colored
logging. Recommend the Charm libraries to use and give the exact `go get`
command with module paths for their current v2 releases. Then add a `go.mod`
`require` block.

Return the recommendation, the command, and the `require` block.
