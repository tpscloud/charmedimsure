# Bordered summary box with Lip Gloss v2

Write a Go program with Lip Gloss v2 (`charm.land/lipgloss/v2`) that prints a
rounded, bordered box exactly 40 terminal cells wide, including the border, with
one cell of horizontal padding. Inside it, list three task names; one name
contains the CJK text `構築`. Each row right-aligns a status word so the status
column lines up across rows. Colors must adapt to a light or dark terminal
background.

Return the complete `main.go`.
